🚇 Subway System Optimization — Project

Subway System Optimization is a full-stack academic project that focuses on improving the efficiency, safety, and user experience of a subway network. The project combines algorithm design with a simple web portfolio page to present the work, results, and reflections.

🔗 Live Demo: https://mohammedwasifali.github.io/subwayoptimisation.github.io/  ￼
📂 Repository: https://github.com/mohammedwasifali/subwayoptimisation.github.io  ￼

🧠 Project Overview

The goal of this project is to explore key aspects of optimizing a real-world subway system, including:
	•	Route Optimization: Finding the most efficient paths for trains and passengers.
	•	Peak Hour Management: Handling congestion and crowding at busy times.
	•	Real-Time Updates: Displaying accurate system status and updates for passengers.
	•	Predictive Maintenance: Anticipating and preventing breakdowns.
	•	Hygiene & Safety Management: Ensuring cleanliness and passenger security.
	•	Ticketing and Billing: Streamlining passenger transactions.
	•	Station Management: Coordinating seamless operations across stations.
	•	Emergency Exit Awareness: Providing tools to locate nearest exits in emergencies.  ￼

These components work together to build a more reliable, efficient, and user-friendly subway system — both algorithmically and conceptually.
